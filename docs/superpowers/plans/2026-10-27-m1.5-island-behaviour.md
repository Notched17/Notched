# M1.5 implementation plan: rename + island behaviour

**Spec:** `docs/superpowers/specs/2026-10-27-m1.5-island-behaviour-design.md` (approved 27 Oct 2026; it is the binding authority).
**Execution:** inline (superpowers:executing-plans), TDD for every piece of pure logic.

## Execution steps

Each step: build (zero warnings) → `scripts/test.sh` → `scripts/install.sh` → screenshot (`screencapture -x -R…`) → **look at the image and critique it against the iPhone and HIG** (`liquid-glass` / `hig-compliance-auditor`) → commit.

0. **Part A:** the rename and clean-up, plus saving the spec and plan docs.
1. **`feat(M1.5): live activity model + coordinator`.** Tests first (B.2 table), then `LiveActivity`, `ActivityPresentation` (types only), `TransientBanner` and the new coordinator. Migrate the sink, the registry and Hello, and delete the old API. Compact temporarily renders the primary only.
2. **`feat(M1.5): presentation regions + expanded layout`.** `ExpandedRegionsGeometry` tests, then the `Layout`, `IslandRegionHost` (island-owned animation), the stale look, and expanded height following content.
3. **`feat(M1.5): compact rendering`.** `CompactLayout` tests, then balanced hugging sides, the auto-hiding trailing side, the asymmetric `compactRect` and the budget.
4. **`feat(M1.5): minimal bubbles + side-by-side`.** Bubbles, bud/merge spring, a goo spike, keyline, per-region sensors, glass bubbles on the pill, and side-by-side mode. Check click-through with `scripts/window-bounds.swift` and `scripts/hit-test.swift`.
5. **`feat(M1.5): alert expansion + transient banners`.** `HoverStateMachine` tests first.
6. **`feat(M1.5): interaction`.** `SwipeRecognizer` tests first. Then click → openAction, bubble → primary, hover-the-hovered activity, swipes, right-click Hide, pages + indicator, the Home activity list, Esc.
7. **`feat(M1.5): settings`.** `SettingsStore` tests first, then the panes.
8. **`feat(M1.5): Scenario Lab`.** Demos built to production quality.
9. **`chore(M1.5): verify, screenshots, performance, ADRs, roadmap`.**
