# M2 Media Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Media module, M2 features #9–#13, #15, #16 and the #5 follow-up. It is a `.media` live activity fed by mediaremote-adapter, with a Music/Spotify scripting fallback, a render-server visualiser, an output switcher, a Music like button and LRCLIB lyrics.

**Architecture:**
- Services (`Sources/Services/NowPlaying`, `Audio`, `Lyrics`) hold the system integrations. They are pure value types plus thin process, CoreAudio and HTTP shells.
- `Sources/Modules/Media` turns their state into one `LiveActivity` posted through the module's `ActivitySink`. Views read a `MediaModel` (`@Observable`), and the module re-posts on significant changes so the island animates them.

**Tech Stack:** Swift 6, SwiftUI, AppKit, Core Animation, CoreAudio, NSAppleScript, Foundation `Process`, URLSession, Swift Testing, XcodeGen.

**Spec:** `docs/superpowers/specs/2026-10-28-m2-media-design.md`

## Global Constraints

- Every source file starts with `// SPDX-License-Identifier: GPL-3.0-or-later`. Vendored files keep their own BSD-3 header plus `Vendor/mediaremote-adapter/LICENSE`.
- Swift 6 strict concurrency. UI and models are `@MainActor`. Process and script work runs off the main thread and hands `Sendable` values back.
- A disabled module costs zero: no process, listener, observer or timer after `stop()`.
- No network calls unless lyrics are enabled.
- Never send an Apple Event to an app that isn't running.
- Logging uses `Log.module("media")`, never `print`.
- Budget: idle with nothing playing < 0.5% CPU; playing and compact < 1.5%; expanded with the visualiser < 3% (perl helper included); memory < 150 MB.
- Build, test and perf runs go through the `build-runner` agent. Install with `scripts/install.sh`, then screenshot with `screencapture`.

## Review Focus

1. **Live streams and radio:** no duration. Expect no scrubber, a "LIVE" label, and no ±15 s unless supported. Test: `PlaybackTimelineTests.liveHasNoProgress`.
2. **Adapter output split across reads, or a malformed line:** expect lines to be buffered to `\n` and bad lines skipped. Tests: `AdapterStreamDecoderTests.partialLinesAreBuffered`, `.malformedLineIsSkipped`.
3. **A player quitting while playing:** expect the activity to end at once, with no ghost. Tests: `AdapterStreamDecoderTests.emptyPayloadMeansNothingPlaying`, `MediaLifecycleTests.nothingPlayingEndsNow`.
4. **Artwork that arrives after the track, or never:** expect a placeholder, then a blur-replace, and the tint to fall back to white. Test: `ArtworkColorTests.greyscaleGivesWhite`.
5. **Elapsed time past the duration, or rate ≠ 1 (podcasts at 1.5×):** expect a clamped result scaled by rate. Tests: `PlaybackTimelineTests.clampsToDuration`, `.scalesByRate`.

### Task 2: Now Playing core types and pure logic (TDD)

**Files:**

- Test: `Tests/PlaybackTimelineTests.swift`, `Tests/AdapterStreamDecoderTests.swift`, `Tests/BackendSelectorTests.swift`

**Interfaces (Produces):**
- `struct PlaybackTimeline: Equatable, Sendable { var elapsed: TimeInterval; var timestamp: Date; var rate: Double; var duration: TimeInterval?; func elapsed(at: Date) -> TimeInterval; func remaining(at: Date) -> TimeInterval?; func fraction(at: Date) -> Double? }`
- `struct TrackKey: Hashable, Sendable { title, artist, album }`
- `struct NowPlayingSnapshot: Equatable, Sendable { title; artist: String?; album: String?; timeline: PlaybackTimeline; isPlaying: Bool; sourceBundleID: String; artwork: Data?; supportsSkip15: Bool; liked: Bool?; var trackKey: TrackKey { get } }`
- `enum MediaCommand: Sendable { case play, pause, togglePlayPause, next, previous, skipForward15, skipBackward15, seek(TimeInterval) }`
- `struct AdapterStreamDecoder { mutating func feed(_ data: Data) -> [AdapterEvent] }`, where `enum AdapterEvent { case nowPlaying(NowPlayingSnapshot?) }`. It buffers to `\n`, applies `diff` payloads onto the last full state, and treats `null` as "remove the key". An empty or untitled state gives `nil`.
- `enum NowPlayingBackend: String, Sendable { case adapter, scripting }`, `enum BackendPreference: String, CaseIterable, Sendable { case auto, adapterOnly, scriptingOnly }`, `enum AdapterHealth: Equatable, Sendable { case unknown, healthy, failed(String) }`, `struct ScriptingAvailability: Equatable, Sendable { var installedApps: Set<String>; var deniedApps: Set<String>; var isAvailable: Bool }`
- `enum BackendSelection: Equatable { case active(NowPlayingBackend), unavailable(UnavailableReason) }`, `enum UnavailableReason: Equatable { case adapterFailed(String), noScriptablePlayers, automationDenied, adapterFailedAndNoFallback(String) }`
- `static func BackendSelector.select(preference:health:scripting:) -> BackendSelection`

- [ ] **Step 1: Write the failing tests**
  - `PlaybackTimelineTests`:
    - `interpolatesWhilePlaying`: elapsed 10 at t0, rate 1 → `elapsed(at: t0+5) == 15`.
    - `pausedDoesNotMove`: rate 0 → 10.
    - `scalesByRate`: rate 1.5 → `10 + 7.5`.
    - `clampsToDuration`: duration 12 → 12; also never < 0.
    - `liveHasNoProgress`: duration nil → `fraction == nil`, `remaining == nil`.
  - `AdapterStreamDecoderTests`:
    - `fullPayloadDecodes`: the fixture line from the 27.2 spike with `durationMicros 196652000` gives duration 196.652, bundle `com.spotify.client`, `isPlaying` false.

    - `nullRemovesKey`: an `artist: null` diff gives artist nil.
    - `partialLinesAreBuffered`: one line fed in 2 chunks gives exactly 1 event, after the second chunk.
    - `malformedLineIsSkipped`: `{oops\n` then a valid line gives 1 event.
    - `emptyPayloadMeansNothingPlaying`: `{"type":"data","diff":false,"payload":{}}` gives `.nowPlaying(nil)`.
    - `parentBundleWins`: `parentApplicationBundleIdentifier` gives `sourceBundleID`.
    - `artworkDecodes`: base64 `artworkData` gives the bytes.

    - `autoPrefersAdapter`
    - `autoFallsBackWhenAdapterFailed`

    - `allDeniedIsAutomationDenied`

  - `func currentFavorited() async -> Bool?`
